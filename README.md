# Jonathan Thangadurai

Build a polished, responsive personal portfolio website for **Jonathan Thangadurai Selvaraj**, a technical product and integration professional based in Amsterdam.

## Objective

Create a website that presents Jonathan as a multidimensional professional with experience spanning:

- Technical product ownership
- Enterprise systems integration
- Data and AI products
- Technical consulting
- Project delivery
- Organisational and process improvement

The website should feel personal, thoughtful, modern, and credible. It must not resemble a CV copied into a webpage, a job-application landing page, or a generic developer portfolio.

The primary audience is hiring managers, product and technology leaders, potential collaborators, and organisations looking for someone who can connect technical systems, stakeholder needs, and practical delivery.

## Brand direction

Use a clean, editorial, European technology aesthetic.

Visual qualities:

- Spacious and calm
- Strong typography and hierarchy
- Warm off-white or very light grey background
- Deep navy or charcoal text
- One restrained accent colour such as cobalt blue
- Subtle borders and generous whitespace
- Minimal use of cards
- No excessive gradients, glassmorphism, glowing effects, stock illustrations, or generic technology imagery
- No skill-percentage bars
- No profile photograph unless one is provided
- If a hero visual is needed, create a restrained abstract systems or connection motif using CSS or simple SVG lines and nodes

Use a modern sans-serif font such as Inter, Manrope, Geist, or a similar alternative. Small labels may use a tasteful monospace font.

The design should feel like a well-designed product or consultancy website rather than a résumé template.

## Technical requirements

Build the website using React, TypeScript and Tailwind CSS.

Requirements:

- Fully responsive
- Accessible semantic HTML
- Keyboard navigable
- Strong colour contrast
- Fast-loading
- Reusable components
- Content stored in structured data objects where practical
- Clean desktop and mobile layouts
- SEO metadata and Open Graph tags
- Descriptive page title and meta description
- No unnecessary dependencies
- No backend required
- No fabricated testimonials, awards, employers, projects, statistics or qualifications
- No placeholder text
- No generic stock photography
- Do not make the website feel tailored to one specific vacancy or employer

Before finishing, check the page at mobile, tablet and desktop widths. Ensure that headings do not wrap awkwardly, the timeline remains readable, contact links work, and the page feels spacious rather than crowded.
